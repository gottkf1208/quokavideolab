# 쿼카 비디오랩 · 교육영상 편집기 ✦

클로드가 만든 초안을 선생님이 직접 다듬는 편집 화면입니다. 무거운 일(최종 렌더, 받아쓰기, 뉴테이크 생성, 브루 더빙)은 클로드에게 넘깁니다.

- 열기: https://gottkf1208.github.io/quokavideolab/
- 예시: https://gottkf1208.github.io/quokavideolab/?demo

## 이렇게 써요

1. **재료 → 폴더 열기**(크롬). 영상·사진·음악·HTML이 든 폴더를 고르면 재료가 보이고, 편집 설계도 `quokavideolab.json`이 그 폴더에 자동 저장돼요. 파일은 브라우저 밖으로 나가지 않아요.
2. 재료의 **넣기**를 누르면 타임라인에 들어가요. 영상은 '영상 액자'(둥근 카드)로, 비율이 같으면 꽉 채움으로 들어가요.
3. 왼쪽 **편집 화면**에서 끌어서 옮기고 모서리로 크기를 바꿔요. 오른쪽 **완성 미리보기**는 영상 뽑기와 같은 틀로 그려져요.
4. 할 일을 **메모**로 남기고 **✦ 클로드에게 넘기기**를 누르면, 설계도와 `클로드에게.md`가 폴더에 저장되고 클로드에게 할 말이 복사돼요.

## 들어 있는 것

| 코드 애니 | 코드로 만든 애니메이션(HTML)을 그대로. **가상 시계**를 끼워 넣어 재생바 시간에 정확히 맞춰 멈추고 돌림 (CSS 애니메이션·GSAP·requestAnimationFrame·three.js) |

| 뉴테이크 | 목소리·영상 구간·배경음악 부탁 → 클로드가 예상 크레딧을 먼저 알려 드리고 승인 후 생성 |

단축키: 스페이스 재생 · S 자르기 · Ctrl+D 복제 · Delete 지우기 · Ctrl+Z 되돌리기 · ←→ 한 프레임

## 영상 뽑기

편집기의 완성 미리보기와 **같은 무대**를 한 프레임씩 찍어 mp4로 만듭니다. 그래서 미리보기와 똑같이 나와요.

```bash
cd render && npm i && npx playwright install chromium   # 처음 한 번
node render.mjs ../../내영상폴더/quokavideolab.json            # → 폴더/영상이름.mp4
node render.mjs 폴더/quokavideolab.json --draft                # 720 초안
```

- 장면 영상은 ffmpeg로 낱장을 풀어 씁니다(헤드리스 크롬은 H.264를 못 읽음).
- 모션랩 클립이 있으면 모션랩 저장소를 옆 폴더(`../quoka-motion-lab`)에서 찾고, 없으면 받아 옵니다.
- 소리는 장면 영상 소리 + 소리 줄을 섞고, 목소리 나올 때 음악을 사이드체인으로 낮춘 뒤 -16 LUFS · 피크 -1dB로 맞춥니다.

## 편집 설계도 (`quokavideolab.json`)

```js
{ ratio: '9:16', w: 1080, h: 1920, fps: 30,
  assets: { id: { type: 'video|image|audio|html', name, path } },     // path는 설계도 폴더 기준
  tracks: [ { kind: 'bg|scene|code|motion|text|sub|bling|audio', clips: [ { id, start, end, ... } ] } ],
  subStyle: { bar, font, size, x, y, w, h, pal },                       // 자막 전체 기본값 (클립 style이 덮어씀)
  memos: [ { t, text, done } ] }                                         // 클로드에게 맡길 일
```
